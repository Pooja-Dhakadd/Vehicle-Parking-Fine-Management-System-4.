# Vehicle Parking Fine Management System

## Project Overview
The Vehicle Parking Fine Management System is a Java-based desktop application developed using Java Swing and MySQL. It helps administrators manage vehicle parking fines efficiently.

## Features
- Admin Login
- Add New Parking Fines
- View All Fine Records
- Search Vehicle Records
- Mark Fines as Paid
- Delete Fine Records

## Technologies Used
- Java
- Java Swing (GUI)
- MySQL
- JDBC
- Apache NetBeans
- Maven

## Database
Database Name: `parking_management`

Main Tables:
- `users` – Stores admin login details.
- `fines` – Stores vehicle and fine information.

## How to Run
1. Download and extract `LM.zip`.
2. Open the project in Apache NetBeans.
3. Start the MySQL server.
4. Create the `parking_management` database and required tables.
5. Add the MySQL Connector/J dependency.
6. Update the database connection settings in `LM.java`.
7. Run the `LM.java` file.
